# 9개 동물 유형 유료 리포트 포지션 가이드

## 1. 문서 목적

이 문서는 9개 동물 유형의 유료 리포트를 작성하거나 수정할 때 유형별 차이를 유지하기 위한 기준이다.

모든 리포트는 동일한 12개 섹션 구조를 사용할 수 있지만, 다음 항목은 유형마다 분명히 달라야 한다.

- 돈이 커지는 방식
- 돈이 새는 방식
- 핵심 자산
- 수익화 방식
- 막히는 지점
- 피해야 할 행동
- 이번 주 실행 방향
- Money Map 값

문장 표현보다 **유형별 포지션과 실행 방향**을 우선한다.

## 2. 동물별 핵심 포지션 최종표

| 유형 | 한 줄 포지션 | 재물 흐름 | 강한 축 | 막히는 축 | 핵심 실행 방향 |
|---|---|---|---|---|---|
| 사슴형 | 오래 쌓은 재능과 신뢰로 안정적인 수익을 만드는 유형 | 장기 누적형 | 완성도, 신뢰, 반복, 꾸준함 | 공개 속도, 가격 책정, 판매 제안 | 좋은 결과물을 밖으로 꺼내고 가격을 붙이는 것 |
| 호랑이형 | 기회를 크게 잡고 빠르게 수익을 확장하려는 유형 | 확장 추진형 | 결단력, 실행력, 판 키우기, 추진력 | 검증 전 과확장, 충동 투자, 과한 자신감 | 크게 키우기 전에 작게 검증하는 것 |
| 다람쥐형 | 모아둔 자료와 습관을 상품으로 묶어 수익화하는 유형 | 축적 자료형 | 저장, 관리, 루틴, 자료화 | 계속 모으기만 함, 기회 회피, 너무 싸게 팖 | 모아둔 자료를 묶어 상품으로 만드는 것 |
| 여우형 | 팔리는 흐름을 읽고 감각적인 기획으로 수익을 만드는 유형 | 감각 전환형 | 기획력, 후킹, 상품화 감각, 전환 감각 | 근거 부족, 잦은 방향 전환, 자극적 표현 | 빠른 감각을 근거 있는 기획으로 바꾸는 것 |
| 황소형 | 성실한 실무력과 반복 업무를 계약 수익으로 바꾸는 유형 | 실무 계약형 | 성실함, 실무력, 반복력, 책임감 | 월급 구조에 갇힘, 변화 회피, 소진형 노동 | 반복 가능한 실무를 월 단위 계약으로 만드는 것 |
| 수달형 | 사람과 관계 속에서 수익 기회를 만들고 연결하는 유형 | 관계 수익형 | 친화력, 유연함, 협업, 연결 능력 | 무료 도움, 부탁형 노동, 경계 없는 할인 | 관계를 가격표와 범위가 있는 유료 구조로 바꾸는 것 |
| 토끼형 | 리스크를 줄이고 안전한 실험으로 수익을 만드는 유형 | 안전 실험형 | 위험 감지, 신중함, 세부 점검, 방어력 | 불안, 시도 지연, 완벽한 안전만 기다림 | 불안을 없애기보다 손실이 작은 실험으로 시작하는 것 |
| 매형 | 문제를 정확히 좁히고 날카로운 판단으로 고효율 수익을 만드는 유형 | 진단 전략형 | 판단력, 집중력, 방향성, 전문성 | 분석 과잉, 고객 눈높이 무시, 기준 과다 | 날카로운 판단을 고객이 이해하는 진단 상품으로 바꾸는 것 |
| 백조형 | 감각과 이미지를 고급스러운 브랜드 가치로 바꿔 수익화하는 유형 | 이미지 가치형 | 미감, 브랜딩, 표현력, 고급화 | 이미지 과소비, 매출 상품 부재, 비교심리 | 감각과 이미지를 매출 상품으로 패키지화하는 것 |

## 3. 동물별 수익화 포지션 최종표

| 유형 | 첫 판매 추천 | 필살 수익 확장법 | 피해야 할 방식 | 이번 주 플랜 |
|---|---|---|---|---|
| 사슴형 | PDF 가이드, 미니 상담, 체크리스트, 카드뉴스 | 후기 기반 서비스 → 패키지 → 정기 피드백 | 혼자 준비만 하기, 가격 못 붙이기 | 저장해둔 결과물 1개 공개 |
| 호랑이형 | 전략 진단, 실행 챌린지, 1회 컨설팅, 목표 달성 패키지 | 작은 검증 → 빠른 판매 → 대표 상품 → 고가 프로그램 → 팀·시스템화 | 검증 없이 크게 벌리기, 충동 투자, 과장 광고 | 검증 가능한 작은 런칭 1개 실행 |
| 다람쥐형 | 가계부 템플릿, 체크리스트, 정리 자료, 루틴 가이드 | 자료 묶음 → 템플릿 세트 → 구독·정기 자료 | 너무 싸게 팔기, 계속 모으기만 하기, 기회 회피 | 모아둔 자료 1개를 판매 가능한 템플릿으로 만들기 |
| 여우형 | 상품명, 후킹 문구, 상세페이지 문구, SNS 기획 | 문구 테스트 → 반응 좋은 기획 → 상세페이지·브랜딩 패키지 → 마케팅 상품 | 자극적 후킹만 쓰기, 근거 없이 판매, 잦은 방향 전환 | 반응 좋은 문구 3개를 테스트하고 저장·클릭·문의 기록 |
| 황소형 | 실무 대행, 반복 작업 서비스, 정리형 자료, 관리 서비스 | 단기 작업 → 월 단위 계약 → 장기 고객 | 안정만 고집하기, 퇴근 후 소진형 노동, 변화 회피 | 월 단위로 반복 가능한 서비스 1개 정리 |
| 수달형 | 소규모 모임, 협업 기획, 커뮤니티, 관계형 코칭 | 관계 반응 → 소개 구조 → 커뮤니티·파트너십 | 무료 도움, 부탁형 노동, 경계 없는 할인, 사람에게 휘둘림 | 지인 3명에게 “이걸 유료로 받는다면 필요한지” 물어보기 |
| 토끼형 | 리스크 점검표, 입문 가이드, 초보자 상담, 안전 루틴 | 무료 점검표 → 저위험 입문 상품 → 표준 프로세스 → 관리형 상품 | 완벽한 안전만 기다리기, 시도 미루기, 과한 걱정 | 손실이 작게 설계된 상품 1개 만들기 |
| 매형 | 진단 리포트, 전략 로드맵, 방향 설정 상담, 문제 분석 | 1회 진단 → 전략 패키지 → 프리미엄 컨설팅 → 고가 자문 | 분석만 오래 하기, 고객 눈높이 무시, 기준 과다 | 자주 보이는 문제 1개를 진단 리포트로 만들기 |
| 백조형 | 프로필 정리, 브랜드 톤 제안, 이미지 컨설팅, 디자인 시안 | 샘플 공개 → 이미지 개선 상품 → 프리미엄 패키지 → 정기 브랜딩 관리 | 꾸미는 데만 돈 쓰기, 매출 상품 부재, 비교심리 | Before·After가 보이는 포트폴리오 샘플 1개 공개 |

| 다람쥐형 | 높음 | 느림 | 보수적인 편 | 중간~높음 | 낮음 | 낮음 | 중간~높음 | 높음 |
| 여우형 | 중간 | 빠름 | 유연한 편 | 중간 | 높음 | 중간~높음 | 중간 | 중간~높음 |

| 매형 | 높음 | 중간~빠름 | 높게 잡는 편 | 중간~높음 | 중간 | 중간 | 중간 | 높음 |
| 백조형 | 중간~높음 | 중간 | 높게 잡고 흔들리는 편 | 중간 | 중간 | 중간~높음 | 중간~높음 | 높음 |

### Money Map 사용 원칙

- 값은 유형 간 차이가 눈에 보이도록 유지한다.
- 모든 유형을 비슷한 값으로 평준화하지 않는다.
- 서술형 문장과 Money Map 값이 충돌하지 않아야 한다.
- Money Map 값은 성향의 절대 평가가 아니라 상대적 경향을 나타낸다.
- 수치를 임의로 높이거나 낮춰 유형의 매력을 보정하지 않는다.

## 5. 유사 유형 차별화 기준

### 5.1 사슴형 · 황소형 · 다람쥐형

| 유형 | 핵심 자산 | 돈 버는 방식 |
|---|---|---|
| 사슴형 | 재능, 완성도, 신뢰 | 결과물을 공개하고 후기 기반 서비스로 키움 |
| 황소형 | 실무력, 성실함, 반복력 | 반복 업무를 월 단위 계약으로 만듦 |
| 다람쥐형 | 자료, 습관, 관리력 | 모아둔 것을 템플릿·자료집으로 묶음 |

#### 사슴형

좋은 결과물이 있지만 공개와 판매가 늦은 유형이다.

- 돈이 커지는 방식: 결과물을 보여주고 신뢰를 쌓아 후기 기반 서비스로 확장
- 돈이 새는 방식: 혼자 준비만 오래 하거나 가격을 붙이지 못함

#### 황소형

성실하게 반복 업무를 해낼 수 있는 유형이다.

- 돈이 커지는 방식: 반복 가능한 실무를 월 단위 계약으로 전환
- 돈이 새는 방식: 안정만 고집하다가 퇴근 후 소진형 노동에 갇힘

#### 다람쥐형

모아둔 자료와 루틴이 많은 유형이다.

- 돈이 커지는 방식: 자료, 체크리스트, 루틴을 템플릿이나 자료집으로 구성
- 돈이 새는 방식: 계속 모으기만 하거나 너무 낮은 가격으로 판매

### 5.2 여우형 · 백조형

| 유형 | 핵심 자산 | 돈 버는 방식 |
|---|---|---|
| 여우형 | 기획력, 후킹, 전환 감각 | 팔리는 문구·기획·상세페이지로 수익화 |
| 백조형 | 이미지, 미감, 브랜딩 | 고급스러운 인상과 브랜드 패키지로 수익화 |

#### 여우형

팔리게 만드는 감각이 핵심이다.

- 돈이 커지는 방식: 상품명, 후킹 문구, 상세페이지, SNS 기획처럼 구매 행동을 만드는 기획으로 수익화
- 돈이 새는 방식: 근거 없이 자극적인 후킹만 앞세우거나 방향을 자주 바꿈

#### 백조형

비싸 보이게 만드는 감각이 핵심이다.

- 돈이 커지는 방식: 프로필, 브랜드 톤, 이미지 개선, 프리미엄 패키지처럼 인상을 가치로 전환
- 돈이 새는 방식: 이미지 소비만 반복하고 실제 매출 상품으로 연결하지 못함

### 5.3 호랑이형 · 매형

| 유형 | 핵심 자산 | 돈 버는 방식 |
|---|---|---|
| 호랑이형 | 추진력, 확장력 | 검증된 상품을 빠르게 키움 |
| 매형 | 판단력, 집중력 | 문제 진단과 전략 설계로 고효율 수익화 |

#### 호랑이형

판을 키우는 유형이다.

- 돈이 커지는 방식: 작은 검증을 통과한 상품을 빠르게 판매하고 고가 프로그램이나 팀 구조로 확장
- 돈이 새는 방식: 검증 없이 크게 벌리거나 충동적으로 투자

#### 매형

문제를 좁히고 정확히 겨누는 유형이다.

- 돈이 커지는 방식: 복잡한 문제를 진단 리포트, 전략 로드맵, 고가 자문으로 전환
- 돈이 새는 방식: 분석만 오래 하거나 고객이 이해하기 어려운 전문 언어로만 설명

### 5.4 다람쥐형 · 토끼형

| 유형 | 핵심 자산 | 돈 버는 방식 |
|---|---|---|
| 다람쥐형 | 축적, 관리, 자료화 | 모아둔 자료를 상품화 |
| 토끼형 | 위험 감지, 안전 설계 | 리스크를 줄이는 가이드·점검 상품화 |

#### 다람쥐형

이미 모아둔 것을 상품으로 묶는 유형이다.

- 돈이 커지는 방식: 축적한 자료를 템플릿, 자료집, 정기 자료로 전환
- 돈이 새는 방식: 계속 준비하고 모으기만 하다가 판매 시점을 놓침

#### 토끼형

손실이 작은 방식으로 실험을 설계하는 유형이다.

- 돈이 커지는 방식: 리스크 점검표, 입문 가이드, 안전 루틴처럼 불안을 줄여주는 상품을 제작
- 돈이 새는 방식: 완벽한 안전을 기다리다가 시도하지 못함

---

## 6. 최종 사용 가이드

### 6.1 유형별 조언을 반복하지 않는다

다음 조언을 모든 유형에 공통으로 사용하지 않는다.

- 작게 공개하기
- 후기 받기
- 가격 붙이기
- 일단 시작하기
- SNS에 올리기
- 상품을 만들어보기

각 조언은 해당 유형의 핵심 막힘과 직접 연결될 때만 사용한다.

### 6.2 핵심 실행 방향을 먼저 고정한다

리포트를 쓰기 전에 다음 질문에 한 문장으로 답한다.

> 이 유형은 무엇을 해야 돈이 커지는가?

이 답이 섹션 전체의 방향을 결정해야 한다.

### 6.3 구조는 통일하고 내용은 다르게 쓴다

- 섹션 구조는 공통으로 유지할 수 있다.
- 핵심 자산, 막히는 지점, 돈이 커지는 방식, 행동 제안은 유형별로 달라야 한다.
- 사슴형의 문장을 동물명만 바꿔 다른 유형에 재사용하지 않는다.

### 6.4 성향 설명보다 실행 행동을 우선한다

리포트는 성향을 길게 설명하는 문서가 아니라 수익화 행동을 제안하는 실행형 문서다.

각 섹션은 가능한 한 다음 순서를 따른다.

1. 현재 돈 흐름
2. 막히는 이유
3. 돈이 새는 방식
4. 돈이 커지는 방식
5. 이번 주 행동

### 6.5 신살은 보조 해석으로 제한한다

- 신살은 동물 유형의 핵심 포지션을 덮어서는 안 된다.
- 신살 해석이 핵심 포지션과 충돌하면 동물 유형의 포지션을 우선한다.
- 신살은 행동 조언을 보완하는 한정된 근거로만 사용한다.

### 6.6 수익화는 핵심 자산에서 출발한다

| 유형 | 수익화 출발점 |
|---|---|
| 사슴형 | 결과물과 신뢰 |
| 호랑이형 | 확장력과 추진력 |
| 다람쥐형 | 축적한 자료 |
| 여우형 | 전환 감각과 기획력 |
| 황소형 | 실무력과 반복력 |
| 수달형 | 관계와 연결력 |
| 토끼형 | 안전 설계와 위험 감지 |
| 매형 | 진단력과 판단력 |
| 백조형 | 이미지와 브랜드 가치 |

### 6.7 피해야 할 방식도 유형별로 다르게 쓴다

| 유형 | 핵심 리스크 |
|---|---|
| 사슴형 | 공개 지연, 가격 회피 |
| 호랑이형 | 검증 없는 과확장, 충동 투자 |
| 다람쥐형 | 계속 축적만 함, 저가 판매 |
| 여우형 | 자극적 표현, 잦은 방향 전환 |
| 황소형 | 월급 구조 고착, 소진형 노동 |
| 수달형 | 무료 도움, 관계 경계 부재 |
| 토끼형 | 완벽한 안전 대기, 시도 지연 |
| 매형 | 분석 과잉, 고객 눈높이 무시 |
| 백조형 | 이미지 소비, 매출 상품 부재 |

### 6.8 감성보다 실행 문서 형식을 우선한다

최종 리포트는 다음 형식을 우선한다.

- 표
- 번호 목록
- 단계
- 체크리스트
- 구체적인 상품 예시
- 이번 주 실행 항목

비유와 감성 문장은 이해를 돕는 보조 수단으로만 사용한다.

## 7. 콘텐츠 작성 규칙

### 7.1 반드시 포함할 내용

각 유형의 리포트에는 다음이 드러나야 한다.

- 핵심 자산
- 돈이 커지는 방식
- 돈이 새는 방식
- 수익화 가능한 상품 또는 서비스
- 피해야 할 방식
- 이번 주 실행 방향

### 7.2 피해야 할 문장

다음과 같은 일반적 문장을 근거 없이 반복하지 않는다.

- 당신은 잠재력이 많습니다.
- 기회를 잡으면 크게 성장할 수 있습니다.
- 꾸준히 하면 성공할 수 있습니다.
- 자신을 믿고 도전해보세요.
- 작은 것부터 시작해보세요.
- 돈의 흐름을 잘 관리해야 합니다.
- 당신만의 강점을 살려보세요.

이러한 문장을 사용해야 한다면 반드시 유형별 자산과 구체 행동을 함께 제시한다.

### 7.3 문장 구조

- 결론을 먼저 쓴다.
- 한 문단에는 하나의 주장만 둔다.
- 같은 의미를 표현만 바꿔 반복하지 않는다.
- 추상어 뒤에는 구체적인 행동이나 예시를 붙인다.
- 고객이 바로 이해할 수 있는 언어를 사용한다.
- 전문 용어는 설명 없이 단독으로 사용하지 않는다.

### 7.4 유료 리포트 가치 기준

유료 리포트는 무료 결과보다 다음이 더 구체적이어야 한다.

- 왜 이 유형이 이런 돈 패턴을 보이는지
- 어떤 상황에서 돈이 새는지
- 어떤 상품이나 서비스로 전환할 수 있는지
- 무엇을 먼저 검증해야 하는지
- 이번 주에 무엇을 해야 하는지

무료 결과와 같은 설명을 길게 반복하지 않는다.

## 8. 섹션 단위 수정 절차

전체 유형을 한 마리씩 수정하지 않고 **동일 섹션을 9개 유형에서 비교하며 수정**한다.

권장 순서:

1. 수정할 섹션의 목적 확인
2. 9개 유형의 현재 문구를 한 번에 비교
3. 공통 문장과 중복 조언 표시
4. 본 가이드의 포지션과 충돌하는 문장 표시
5. 유형별 돈이 커지는 방식과 새는 방식을 다시 고정
6. 9개 유형 문구 수정
7. 유형 간 차별성 검수
8. 타입·필드·렌더링 검증
9. 다음 섹션으로 이동

한 번에 1~2개 섹션만 처리한다.

## 9. 유형별 차별성 검수 체크리스트

각 섹션 수정 후 다음을 확인한다.

- [ ] 동물명을 다른 유형으로 바꿔도 자연스러운 범용 문장이 아닌가?
- [ ] 핵심 자산이 본 가이드와 일치하는가?
- [ ] 돈이 커지는 방식이 다른 유형과 구분되는가?
- [ ] 돈이 새는 방식이 다른 유형과 구분되는가?
- [ ] 실행 방향이 해당 유형의 막히는 축을 직접 해결하는가?
- [ ] 추천 상품이 핵심 자산에서 출발하는가?
- [ ] Money Map 값과 서술 내용이 충돌하지 않는가?
- [ ] 모든 유형에 ‘작게 공개하기’를 반복하지 않았는가?
- [ ] 무료 결과의 문장을 길게 재사용하지 않았는가?
- [ ] 신살이 동물 유형의 핵심 포지션을 덮지 않는가?
- [ ] 감성 문장보다 실행 정보가 더 많은가?
- [ ] 사용자가 이번 주에 할 행동을 바로 찾을 수 있는가?

## 10. 유형 간 오염 방지 규칙

다음 포지션을 서로 섞지 않는다.

- 사슴형의 공개·후기 전략을 황소형의 핵심 전략으로 사용하지 않는다.
- 황소형의 월 계약화를 다람쥐형의 핵심 전략으로 사용하지 않는다.
- 다람쥐형의 자료 상품화를 토끼형의 안전 설계와 동일하게 쓰지 않는다.
- 여우형의 구매 전환 기획을 백조형의 이미지 가치와 혼동하지 않는다.
- 호랑이형의 확장 전략을 매형의 진단 전략과 혼동하지 않는다.
- 수달형의 관계 수익화를 단순 SNS 노출 전략으로 축소하지 않는다.
- 토끼형에게 과감한 확장이나 고위험 실험을 핵심 행동으로 제시하지 않는다.
- 백조형에게 이미지 개선만 제안하고 실제 매출 상품을 누락하지 않는다.
- 매형에게 전문성만 강조하고 고객이 구매할 수 있는 진단 상품을 누락하지 않는다.

## 11. Codex 작업 규칙

Codex가 유료 리포트를 수정할 때는 다음 순서를 따른다.

1. 이 문서를 먼저 읽는다.
2. 현재 수정할 섹션과 관련된 9개 유형 원문을 모두 읽는다.
3. 코드 수정 전에 유형 간 중복과 포지션 충돌을 정리한다.
4. 사용자 승인 없이 12개 섹션 전체를 한 번에 다시 쓰지 않는다.
5. 동일 섹션의 9개 유형을 비교하며 수정한다.
6. 기존 사주·점수·신살·동물 판정 로직은 변경하지 않는다.
7. 확정된 콘텐츠 데이터 타입과 12개 섹션 순서를 유지한다.
8. 새로운 공통 문구를 9개 유형에 일괄 복제하지 않는다.
9. 수정 후 본 문서의 체크리스트로 자체 검수한다.
10. 타입 검사, 테스트, 빌드와 렌더링 검증을 수행한다.

## 12. Source of Truth 충돌 처리

내용이 충돌하면 다음 우선순위를 사용한다.

1. 사용자가 직접 승인한 최신 요구
2. 본 문서의 동물별 핵심 포지션
3. 현재 확정된 유료 리포트 섹션 구조
4. 기존 유형별 확정 원문
5. 사주·신살 보조 해석
6. 일반적인 수익화 조언

일반적인 조언이 유형별 포지션과 충돌하면 삭제하거나 해당 유형에 맞게 다시 작성한다.
