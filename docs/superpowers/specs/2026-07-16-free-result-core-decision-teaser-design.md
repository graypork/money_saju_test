# 무료 결과: 핵심 판정 맛보기 재구성 명세

## 목적

기존 무료 결과 화면은 독립된 완성형 해석으로 구성되어 있어 유료 리포트와 역할이 겹친다. 이를 제거하고, 무료 결과를 유료 리포트의 분석 밀도와 방향을 짧게 체감시키는 **핵심 판정 맛보기**로 재구성한다.

사용자는 화면을 본 뒤 다음을 즉시 이해해야 한다.

> 내 재물 흐름의 핵심 판정은 무엇이며, 왜 상세 리포트를 봐야 하는가.

## 확정한 방향

`A. 핵심 판정 카드형`을 적용한다.

무료 결과는 다음 순서만 유지한다.

1. 핵심 판정
2. 판정의 짧은 근거 2개
3. 잠긴 상세 분석 맛보기
4. 유료 리포트 진입 CTA

기존의 장문 무료 결과 카드(오행 균형, 돈 흐름 요약, 강점·주의점 등)는 삭제한다. 내용이 필요한 사용자는 유료 리포트에서 이어서 확인한다.

## 화면 설계

### 1. 핵심 판정

- 상단에 작은 `FREE PREVIEW` 표기와 `핵심 판정` 라벨을 둔다.
- 결과 유형, 상위 퍼센트, 동물 이미지는 한 덩어리의 판정 카드 안에 압축한다.
- 생성된 결과의 의미를 바꾸지 않고, 기존 결과 제목과 요약 문장을 결론으로 사용한다.
- 숫자·등급은 검정 계열의 강한 대비로, 부가 정보는 투명도를 낮춘 검정으로 위계를 만든다.

### 2. 판정 근거

- 계산 결과에서 이미 제공되는 특성만 이용해, 짧은 근거 2개를 제시한다.
- 근거는 ‘강한 흐름’과 ‘주의할 흐름’처럼 서로 다른 역할을 맡는다.
- 새로운 점수, 운세 해석, 생성 결과를 만들지 않는다.

### 3. 잠긴 상세 분석 맛보기

- 유료 리포트에서 이어질 분석 항목을 2~3개의 잠금 행으로 보여준다.
- 각 행은 제목과 매우 짧은 설명만 노출하며, 자세한 본문·결론·리포트 카피는 무료 화면에 복제하지 않는다.
- 잠금 상태는 별도 색상 블록이나 과한 장식 대신, 낮은 대비·마스크·자물쇠 표시로 구분한다.

### 4. 행동 유도

- 하단의 주 행동은 `상세 리포트에서 분석 이어보기` 한 가지다.
- 버튼은 `/report`로 현재 쿼리 파라미터를 그대로 전달한다.
- ‘다시 테스트하기’는 보조 텍스트 링크로만 제공한다.

## 시각 원칙

- 확정된 B 방향을 따른다: Pretendard, 검정 계열 위계, 따뜻한 포인트 색은 최소 사용.
- 크림·그린·테라코타, 세리프, 기록지·도장 같은 C 방향 요소를 사용하지 않는다.
- 모바일 390~430px에서 한 화면에 핵심 판정과 CTA의 존재가 함께 감지되도록 밀도를 조절한다.
- 장식성 이미지보다 판정 문장과 정보 위계를 우선한다. 동물 이미지는 결과 식별을 돕는 보조 요소로만 쓴다.

## 동작 및 보존 범위

- `/result` 경로와 현재 쿼리 파라미터를 유지한다.
- 사주 계산, 동물 매핑, 결과 카피 생성, 결과 로그 저장, `admin22` 제외 처리, 결제·잠금·리포트 진입 동작을 보존한다.
- 유료 리포트의 카피, 섹션 순서, 생성된 결과 의미는 변경하지 않는다.
- 결과 계산이나 화면 전환을 위한 추가 애니메이션은 넣지 않는다. 잠금 미리보기는 정적인 상태로 유지한다.

## 완료 기준

- 기존 장문 무료 결과 섹션이 화면에서 사라진다.
- 핵심 판정, 근거 2개, 잠긴 미리보기, 단일 유료 CTA가 순서대로 보인다.
- 유료 CTA가 동일한 쿼리 파라미터로 리포트 화면에 이동한다.
- 계산·로그·`admin22` 예외 및 빌드가 유지된다.
