# 상세 리포트 이어 읽기 설계 명세

## 목적

상세 리포트를 카드 모음이 아니라, 사용자가 한 분석을 읽은 뒤 자연스럽게 다음 분석을 궁금해하며 이어 읽는 흐름으로 만든다.

## 확정한 경험

사용자는 2열 모자이크에서 관심 있는 카드를 고른다. 확장된 카드에서는 원문이 아래 순서로 읽힌다.

1. 이 카드의 핵심 결론
2. 결론의 이유와 구체적 설명
3. 바로 적용할 행동 또는 비교 정보
4. 다음 분석의 제목과 `다음 분석 읽기` 행동

`다음 분석 읽기`를 누르면 기존 확장 전환 로직으로 현재 카드를 접고, 원래 섹션 순서에서 바로 다음 카드를 연다.

## 본문 구조

### 문단

- 원문의 줄바꿈을 독립 문단으로 표시해 한 덩어리의 긴 텍스트로 보이지 않게 한다.
- 첫 문단은 카드의 핵심 결론으로 더 큰 크기와 높은 검정 대비를 사용한다.
- 이후 문단은 일반 본문 크기와 넓은 행간으로 표시한다.
- 문장 순서와 문구는 변경하지 않는다.

### 강조 블록

- 일반 강조 블록은 라벨, 결론 문장, 보조 설명 순으로 읽힌다.
- 원문 안에 `문제`, `손실`, `해법`이 줄바꿈으로 포함된 경우 세 부분을 같은 순서의 세로 단계로 표시한다.
- 각 단계의 원문 텍스트는 바꾸지 않는다.

### 목록과 표

- 목록은 제목, 각 항목의 넓은 행 순으로 유지한다.
- 모바일 표는 이미 적용된 헤더-값 세로 행을 유지한다.
- 표의 행·열 순서와 모든 셀 값은 유지한다.

## 다음 분석 연결

- 확장된 카드의 마지막에는 다음 섹션의 기존 제목만 노출한다.
- 마지막 섹션에는 다음 분석 행동을 표시하지 않는다.
- 버튼은 기존 `handleToggle(nextIndex)` 흐름을 재사용하며, 별도 라우트·저장소·결제 동작을 만들지 않는다.

## 보존 조건

- 리포트 원문, 섹션 순서, 샘플 매핑, 사주 계산, 쿼리, 로그, 결제·잠금 동작은 변경하지 않는다.
- `BASE_PLACEMENTS`, `collapsedLayout`, `expandedLayout`, `animateLayoutChange`, `aria-expanded`, 포커스와 모션 감소 처리를 보존한다.
- 새 패키지, 새 라우트, 자동 재생 모션을 추가하지 않는다.
