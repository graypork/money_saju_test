# B 흐름·위계 재설계 — 설계 명세

> 상태: 2026-07-16 사용자 승인 완료. 구현은 아직 시작하지 않음.

## 목표

랜딩에서 무료 결과, 상세 리포트까지의 모바일 여정을 개선한다. 제품 로직, 리포트 의미, 라우트 계약은 바꾸지 않는다. 방문자는 빠르게 시작하고, 지금 받은 결과를 이해하며, 상세 리포트를 맥락을 잃지 않고 훑을 수 있어야 한다.

## 선택한 방향

이 작업은 **B. 흐름·위계 재설계**다. 현재 제품 정체성 중 의미 있는 요소는 보존하되, 거절된 C 방향을 다시 만들지 않는다.

C에서 제외하는 요소는 세리프 디스플레이 서체, 표본/기록철 은유, 인장형 마크, 큰 테라코타 이미지 패널, 새로운 전면 시각 시스템이다. 이 요소들은 구현 후보가 아니다.

## 시각 시스템

### 팔레트

다음 기존 표면·강조 색은 유지한다.

- 허니 페이지 배경: `#F3D58B`
- 크림 표면: `#FFF8ED`
- 로즈 주요 강조: `#D98E73`
- 소프트 로즈 보조 표면: `#E7C5B8`

고객 대상 화면에서는 브라운 계열 텍스트/잉크 사용을 없앤다. 특히 기존 다크 브라운 `#33241D`, 뮤트 브라운 `#82685D`의 텍스트 역할은 아래 중립 검정 계층으로 바꾼다.

- 주요 텍스트와 결정적 컨트롤: `#000000`
- 일반 본문: `rgba(0, 0, 0, 0.72)`
- 보조 라벨과 낮은 우선순위 메타데이터: `rgba(0, 0, 0, 0.48)`
- 구분선과 비활성 경계: `rgba(0, 0, 0, 0.14)`

로즈는 행동과 상태를 알리는 강조색으로만 사용한다. 텍스트 강조는 추가 브라운 색이나 장식적 색상 변화가 아니라 검정의 농도, 굵기, 자간, 크기로 만든다.

### 서체와 텍스트 처리

기존 로컬 Pretendard 가변 서체를 앱의 유일한 서체로 유지한다. 세리프 디스플레이 서체, 고객 대상 콘텐츠의 모노스페이스 서체, 장식 목적의 영문 전체 대문자는 도입하지 않는다.

- 핵심 메시지는 대비가 높은 검정의 간결한 한글 제목으로 쓴다.
- 반복되는 `font-black` 대신 절제된 크기·굵기 단계를 쓴다.
- 메타데이터는 실제 의미가 있는 라벨과 낮은 검정 농도로 처리한다.
- 굵은 글자는 결과 타입, 핵심 행동, 섹션 제목에만 사용하며 모든 카드·필·라벨에 반복하지 않는다.

### 이미지와 표면

기존 동물 이미지는 결과와 직접 연결된 증거로만 유지한다. 결과와 관련 소개 콘텐츠에서는 분명하게 보이되, 제품 전체의 새 상징, 풀블리드 색면, 인장 시스템으로 만들지 않는다.

터치에 도움이 되는 기존의 둥근 모바일 표면은 유지하되, 경쟁하는 그림자·필·테두리 수를 줄인다. 허니는 페이지를 만들고, 크림은 읽을 내용을 담고, 로즈는 주요 행동/선택 상태를 알리며, 검정은 위계를 만든다.

## 화면별 경험

### 랜딩

첫 화면에서 테스트의 약속을 제시하고 생년 정보 입력 폼으로 즉시 이동할 수 있어야 한다. 설명 덱과 동물 소개는 유지하지만 시작 흐름을 가로막지 않는다. 설명 덱은 콘텐츠를 유지하면서 포인터 스와이프 외의 이해 가능한 진행 방법을 제공한다.

### 입력

폼은 하나의 간결한 작업으로 읽혀야 한다. 기존 값, 유효성 검사, 쿼리 파라미터, `testCaseCode`, 이후 `admin22` 제외 동작은 바꾸지 않는다. 필드는 명시적인 시맨틱 관계를 갖고, 현재 모바일 피커는 포커스·다이얼로그 동작을 보완한다. QA/테스트 코드 접근은 일반 입력보다 시각적으로 보조적인 위치에 둔다.

### 무료 결과와 상세 리포트 진입

현재 비율, 동물 정체성, 오행 신호, 생성된 문구, 로깅, 저장소 동작은 유지한다. 반복되는 경쟁 CTA 대신 하나의 전진 행동을 만든다. 전환 문구는 현재 읽고 있는 무료 결과와 상세 리포트에서 추가로 읽을 내용을 먼저 설명하며, 현 라우트가 제공하지 않는 구매/잠금 완료나 동물별 상세 리포트를 약속하지 않는다.

### 리포트

현재 2열 모자이크를 주요 탐색 모델로 유지한다. 카드 위계, 텍스트 대비, 선택/확장 상태, 개요 동작을 정리해 보이는 행동은 모두 동작하게 한다. 섹션 순서, 리포트 문구, `aria-expanded`, 포커스 스타일, 모션 감소 동작을 보존한다. 현재 임시 백조 샘플 매핑은 이 작업에서 바꾸지 않는다.

## 변경 불가 조건

- `/`, `/input`, `/result`, `/report`와 모든 현재 쿼리 계약을 보존한다.
- 사주 계산, 점수, 동물 매핑, 생성 결과 의미, 리포트 문구, 로깅, 로컬/세션 저장소, 결제, 잠금, `admin22` 제외 동작을 보존한다.
- 패키지, 결제 시스템, 체크아웃, 라우트 구조, 데이터베이스, 리포트 콘텐츠를 추가·재작성하지 않는다.
- 390–430px 모바일 화면을 대상으로 하며, 포커스 접근성과 모션 감소 선호를 보존한다.

## 완료 기준

- 고객 대상 주요/보조 텍스트는 기존 브라운 텍스트 색 대신 중립 검정 계층을 사용한다.
- 허니·크림·로즈는 표면/행동 역할로 유지하되 C의 표본·기록철 시각 언어는 재도입하지 않는다.
- 랜딩에는 하나의 명확한 시작 경로, 무료 결과에는 하나의 명확한 전진 행동이 있다.
- 입력 흐름은 기능을 보존하면서 폼·피커 시맨틱을 개선한다.
- 리포트는 동작하는 컨트롤과 분명한 선택/확장 상태를 가진 2열 스캔 모자이크로 남는다.
- 기존 결과, 리포트, 쿼리, 저장소, 로깅, 결제/잠금, `admin22` 동작이 그대로 유지된다.
