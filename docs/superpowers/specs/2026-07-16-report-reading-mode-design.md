# 상세 리포트 읽기 모드 설계 명세

## 목적

2열 모자이크는 분석 항목을 고르는 탐색 단계로 유지한다. 사용자가 카드를 확장하면, 같은 카드가 모바일에서 긴 본문을 편안하게 읽는 읽기 모드로 전환된다.

## 확정된 동작 순서

1. 사용자는 2열 모자이크에서 분석 카드를 선택한다.
2. 기존 확장 알고리즘이 선택 카드를 전체 너비로 재배치한다.
3. 확장 카드의 제목·접기 동작은 상단에 고정되고, 본문은 읽기 전용 밀도로 바뀐다.
4. 주변의 미선택 카드는 다음 탐색 대상으로 남되, 불투명도를 낮춰 본문과 경쟁하지 않게 한다.
5. 접기를 누르면 기존 2열 모자이크와 원래 카드 대비로 돌아간다.

## 읽기 모드 구성

- 확장 카드는 로즈 경계와 넓은 크림 표면을 유지한다.
- 제목 아래 경계로 제목/본문을 분리한다.
- 문단은 16px과 넓은 행간을 사용한다.
- 목록은 항목 하나당 넓은 세로 행으로 표시한다.
- 표는 390~430px에서 헤더-값 쌍의 세로 정보 행으로 바꾼다. 원본 헤더·셀 값·순서는 바꾸지 않는다.
- 제목의 접기 동작은 기존 `aria-expanded`와 포커스 동작을 보존한다.

## 보존 조건

- `BASE_PLACEMENTS`, `collapsedLayout`, `expandedLayout`, `animateLayoutChange`와 기존 모션 감소 처리를 변경하지 않는다.
- 리포트 카피, 섹션 순서, 샘플 리포트 매핑, 쿼리 문자열, 점수·결제·잠금 동작을 변경하지 않는다.
- 새 패키지와 새 애니메이션을 추가하지 않는다.
